### 🌟 Featured Flagship Project

#### 🚀 **[OptiPrice: Marketplace Dynamic Pricing & Demand Elasticity Engine](https://github.com/AkashJambhulkar19/Optiprice-dynamic-pricing)**
> *An end-to-end commercial pricing analytics and econometric modeling platform for multi-category e-commerce.*
> 
> 🔗 **Live Demo**: [optiprice-dynamic-pricing-ssbghzwb997fpztakxmpwv.streamlit.app](https://optiprice-dynamic-pricing-ssbghzwb997fpztakxmpwv.streamlit.app/)

* 📊 **SQL Data Marts**: Built in **DuckDB** using production Window Functions (`ROWS BETWEEN 6 PRECEDING AND CURRENT ROW`), Relative Price Indexing (RPI), and stockout arbitrage tracking.
* 📈 **Econometrics**: Multivariate OLS Log-Log regression ($\ln Q = \alpha + \beta_1 \ln P + \beta_2 \ln P_{\text{comp}}$) estimating Own-Price and Cross-Price Elasticities ($R^2 = 0.81$).
* 💰 **Business ROI**: Solved profit-maximizing repricing rules, uncovering **$48,500/month** in gross margin expansion ($580k+ annualized EBITDA uplift).
* 🖥️ **Executive Cockpit**: Streamlit + Plotly interactive dashboard with real-time "What-If" scenario sliders and a live DuckDB SQL query console.
